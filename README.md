🎓 Student Placement Portal (Spring Boot Version)

A full-stack web application designed to streamline campus placement activities by connecting students, recruiters, and administrators on a single platform.
Built with React (frontend), Spring Boot (backend), and MySQL (database).

✨ Features
Student Profiles – Register and manage academic details.
Job Postings – Companies can list opportunities with eligibility criteria.
Search & Filter – Find jobs by role, company, or requirements.
Admin Dashboard – Manage students, recruiters, and placement records.
Secure Authentication – Role-based login for students, recruiters, and admins.

🛠️ Tech Stack
Frontend: React, Vite, HTML, CSS, JavaScript
Backend: Spring Boot (Java), Spring Security, REST APIs
Database: MySQL
Tools: Git, GitHub, VS Code, Maven
